# Cubic Inverses — Inverse Function Transformations

An interactive Algebra 2 visualization of **inverse functions and their transformations** — reflecting a function across the line *y = x* to see how domain, range, and key points map to the inverse. A single, self-contained HTML page (no install).

## Use it

Open `index.html` in any browser. To share a live link, enable **GitHub Pages** on this repo (Settings → Pages → deploy from `main`) to publish it at `https://happypurple1.github.io/Cubic-Inverses/`.
